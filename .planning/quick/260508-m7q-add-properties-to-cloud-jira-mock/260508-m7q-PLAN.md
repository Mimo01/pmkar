# Quick Plan: Add more properties to cloud jira mock

## Task

Add missing standard Jira fields to all mock issues (both v2 and v3) in `src-tauri/src/fixtures.rs`, inspired by a real v2 ticket from scratch_2.txt.

## Fields to Add

All 16 mock issues (PROJ-1 through PROJ-16) receive:

- `lastViewed` — ISO timestamp string
- `resolutiondate` — null for open/in-progress; date string for resolved/closed
- `duedate` — null or date string (set on bugs with urgency or milestoned stories)
- `environment` — null or string (`"Production"` for production bugs)
- `watches` — `{ "watchCount": N, "isWatching": false }`
- `votes` — `{ "votes": N, "hasVoted": false }`
- `progress` — `{ "progress": N, "total": N }` (reflects time logged vs estimate)
- `timeoriginalestimate` — null or integer seconds
- `aggregatetimeoriginalestimate` — null or integer seconds
- `timetracking` — `{}` or full object with originalEstimate/remainingEstimate/timeSpent
