# Quick Task 260508-a54: Comments Tab — Newest-First Sort with Toggle

**One-liner:** CommentsTab defaults to newest-first via ISO string localeCompare sort with a compact toggle button for flipping to oldest-first.

## What Was Built

- `CommentsTab` now holds `useState<'desc' | 'asc'>('desc')` for sort order
- `sortedComments` derived with `[...comments].sort((a, b) => sortOrder === 'desc' ? b.created.localeCompare(a.created) : a.created.localeCompare(b.created))` — ISO 8601 strings sort lexicographically
- Sort toggle button renders above the list only when `comments.length > 0`; uses `aria-label` from `detail.comments.sortToggle.ariaLabel`
- Button label shows current active order: "Newest first" (desc) or "Oldest first" (asc)
- i18n keys added to both `en.json` and `sk.json`
