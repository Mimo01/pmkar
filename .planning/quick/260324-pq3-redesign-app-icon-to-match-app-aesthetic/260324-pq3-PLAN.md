Redesign the Pmkar app icon to match the app's refined Linear-inspired aesthetic. The current icon has a bold "P" with a chevron element that muddies at small sizes. The redesign keeps the "P" lettermark and brand red but simplifies geometry for clarity at all sizes, adds a subtle gradient for depth, and removes the chevron.

Purpose: The app went through a full UI redesign (Phase 08) to a Linear-inspired minimal aesthetic -- the icon should match.
Output: New SVG source icon + all platform variants regenerated via `npx tauri icon`.
</objective>

<task type="auto">
  <name>Task 1: Redesign the SVG source icon</name>
  <files>src-tauri/icons/app-icon.svg</files>
  <action>
Redesign `src-tauri/icons/app-icon.svg` as a 1024x1024 SVG with these specifications:

**Background:**
- Full 1024x1024 square canvas (macOS applies its own squircle mask)
- Rounded rect with rx="220" ry="220" (same squircle proportion as current)
- Subtle linear gradient from `#a01c2a` (top-left) to `#c02232` (bottom-right) for modern depth, using a `<defs>` gradient definition

**Lettermark "P":**
- Clean, geometric, optically centered "P" in white (#ffffff)
- Remove the forward-motion chevron entirely (it becomes noise at small sizes)
- Use a modern geometric sans-serif style consistent with Lucide icon aesthetic:
  - Clean vertical stem: straight, uniform width (~100-110px)
  - Geometric bowl: smooth arc, consistent stroke weight with stem
  - Bowl interior cutout matches background gradient (use `url(#bg-gradient)`)
- Optically center the P now that chevron is removed (shift slightly right from current x=248)
- Ensure minimum 12.5% padding from edges (~128px inset) per Apple HIG

**Simplicity rules:**
- No more than 6-7 SVG elements total (gradient def, rect, 2-3 path/rect elements)
- No fine details that disappear below 32x32
- No opacity tricks -- solid fills only
- No stroke outlines -- filled shapes only

**Quality check:** The silhouette should be instantly recognizable as a "P" even at 16x16.
