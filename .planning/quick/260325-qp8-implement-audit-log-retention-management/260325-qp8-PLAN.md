In src-tauri/src/audit.rs, add three new methods to the AuditDb impl block:

1. `pub fn prune_old_entries(&self, max_age_days: i64) -> AppResult<u64>` — DELETE FROM audit_log WHERE created_at < strftime('%s','now') - (max_age_days * 86400). Return number of rows deleted via self.conn.execute() return value cast to u64.

2. `pub fn prune_response_bodies(&self, max_age_days: i64) -> AppResult<u64>` — UPDATE audit_log SET response_body = NULL WHERE response_body IS NOT NULL AND created_at < strftime('%s','now') - (max_age_days * 86400). Return number of rows affected.

3. `pub fn vacuum(&self) -> AppResult<()>` — Execute "VACUUM" statement on self.conn.

4. `pub fn get_page(&self, offset: i64, limit: i64) -> AppResult<Vec<AuditEntry>>` — Same query as get_all but with LIMIT ?1 OFFSET ?2 params. Keep ORDER BY id DESC.

Add unit tests in the existing #[cfg(test)] mod:
- test_prune_old_entries: insert entries, manually UPDATE created_at to old timestamps, call prune_old_entries(30), verify old entries removed and recent ones remain.
- test_prune_response_bodies: insert entries with response bodies, set some created_at to 8+ days old, call prune_response_bodies(7), verify old entries have response_body = None while recent ones still have bodies.
- test_get_page: insert 10 entries, verify get_page(0, 5) returns 5, get_page(5, 5) returns 5, get_page(0, 20) returns 10.
- test_vacuum_succeeds: just call vacuum() and assert it returns Ok.

In src-tauri/src/commands.rs, add a new Tauri command:
```rust
#[tauri::command]
pub fn get_audit_logs_page(
    db: State<'_, Arc<Mutex<AuditDb>>>,
    offset: i64,
    limit: i64,
) -> Result<Vec<AuditEntry>, AppError> {
    let db = db.lock().map_err(|_| AppError::Internal("Database lock poisoned".into()))?;
    db.get_page(offset, limit)
}
```
