# Quick Task 260430-0l2: Watched Users hint — auto-inclusion clarification — Summary

One-liner: Updated `settings.watchedUsers.hint` in EN and SK so the user reads, in the Watched Users settings panel, that they are automatically included in "All watched users" results without needing to add themselves.

## What was built

The Watched Users settings panel hint paragraph (rendered at `src/features/connections/SettingsPage.tsx:786` via `t('settings.watchedUsers.hint')`) now communicates a real backend behavior that was previously invisible from the UI: the `build_poll_jql` `all_watched` arm in `src-tauri/src/poll_engine.rs:347` always unions `build_mine_clauses(username)` with the watched-user clauses, so the currently signed-in Jira user is in the result set regardless of whether they are on the watched list.

After:
