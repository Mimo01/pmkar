<objective>
Add static value support for the `issuetype` field in the Pmkar field mapping system. After this plan, users can configure a default issue type once in mapping settings; subsequent copies use that value automatically, bypassing the per-copy IssueTypeChooser (which remains visible but is overridden by the static mapping).

Purpose: Eliminates the friction of re-picking the same target issue type on every copy when a customer's tickets always map to the same target type (e.g., "Bug").

Output: Working static-value picker for issuetype in field mapping settings + override-aware copy pipeline + tests.
</objective>
