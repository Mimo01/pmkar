# Quick Task 260428-499: Widen Settings View Layout

## Goal

The settings view is too narrow (max-w-[560px]), especially the new field mapping section which has a 4-column grid that feels squished. Increase the max-width so all settings sections have more breathing room.

## Tasks

### Task 1: Increase max-width constraint in SettingsPage

**File:** `src/features/connections/SettingsPage.tsx:1225`

**Change:** `max-w-[560px]` → `max-w-[760px]`

**Rationale:** Window is 1024px wide. Sidebar is w-40 (160px), content padding is px-8 (64px total), leaving ~800px usable. 760px gives the field mapping 4-column grid (35fr/35fr/20fr/10fr) enough space to breathe while keeping a small visual margin.
