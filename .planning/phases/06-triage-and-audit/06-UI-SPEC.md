| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding (`px-1.5 py-0.5`) |
| sm | 8px | Compact element spacing, button gaps (`gap-2`) |
| md | 16px | Default element spacing, panel horizontal padding (`px-4`) |
| lg | 20px | Panel horizontal padding for detail/header areas (`px-5 py-4`) |
| xl | 24px | Section padding |
| 2xl | 32px | Layout gaps |
| 3xl | 48px | Major section breaks |

Exceptions:
- Header: `px-5 py-2.5` (10px vertical — established pattern in AppShell)
- Table cell padding: `px-4 py-3` (established in TicketTable)
- Tab bar buttons: `py-2 mr-4` (established in TicketDetailPanel)
- Footer status bar: `px-4 py-1.5` (compact single-line bar, 6px vertical)
- Min touch target for icon-only buttons: 28x28px (`w-7 h-7` — established in AppShell gear)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 regular | 1.5 |
| Label / metadata | 12px (text-xs) | 400 regular | 1.4 |
| Small label / column header | 10px (text-[10px]) | 600 semibold | 1.2 |
| Heading / panel title | 20px (text-xl) | 600 semibold | 1.25 |

Source: established in TicketDetailPanel (`text-xl font-semibold`), TicketTable (`text-[10px] font-semibold uppercase`), table cells (`text-xs`, `text-sm`).

No new font sizes are introduced in Phase 6. All new text elements use one of the four roles above.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#f7f7f8` light / `#161617` dark (`brand-bg`) | App background, page canvas |
| Secondary (30%) | `#ffffff` light / `#1e1e20` dark (`brand-surface`) | Header, table header, cards, nav area |
| Accent (10%) | `#c02232` (`brand`) | Reserved list below |
| Muted text | `#8c8c92` light / `#6b6b6f` dark (`brand-muted`) | Footer link, column headers, secondary actions |
| Destructive | `#f87171` (`red-400`) | Error states and failed step indicators only |

Accent (`brand` / `#c02232`) reserved for:
- AppShell header brand underline gradient
- Active tab indicator (bottom border on selected tab)
- "New" ticket dot in TriageIndicator
- Left border on selected row in TicketTable
- Primary "Copy to Company Jira" button background

The "Not Mine" button and "Undo Not Mine" button use `brand-muted` text with `brand-border` border — NOT accent. This matches existing TicketDetailPanel implementation.

The ignored state indicator in TriageIndicator uses `brand-surface-hover` background with `brand-muted` text — neutral, not accent.

The audit log footer link uses `brand-muted` text at rest, `brand-text` on hover — NOT accent.

Surface states:
- Hover row: `brand-surface-hover` (`#f0f0f2` light / `#28282a` dark)
- Raised surface: `brand-surface-raised` (`#eaeaec` light / `#1a1a1c` dark)
- Borders: `brand-border` (`#e0e0e3`) for primary, `brand-border-subtle` (`#ebebed`) for row dividers

Source: `src/index.css` @theme block, confirmed across all existing component files.

## Component Inventory

New components introduced in Phase 6:

### IgnoredTicketsPage

- Layout: full-page, same layout structure as TicketListPage (header area + scrollable table)
- Table: reuse `TicketTable` component — same columns (key, summary, status, priority, assignee, updated)
- Additional column: "Un-ignore" action button, rightmost column, width `w-24`
- Un-ignore button: `text-xs font-semibold text-brand-muted border border-brand-border rounded px-2 py-1 hover:text-brand-text hover:border-brand-text transition-colors`
- Empty state: centered in the scrollable area, no icon, heading + body copy (see Copywriting Contract)
- Navigation: reachable via "Ignored" tab in AppShell nav (new tab alongside implied "Tickets" navigation)

### AuditLogPage

- Layout: full-page view, same pattern as SettingsPage (replaces main content area, has close button)
- Table: `<table>` with sticky `<thead>`, columns: Timestamp (w-40), Method (w-16), URL (flex-1, truncated), Status (w-16)
- Column header style: `text-[10px] font-semibold uppercase tracking-[0.08em] text-brand-muted` — matches TicketTable
- Row: compact, `py-2` vertical padding, `text-xs` body, `text-brand-text-secondary`
- Expandable row: clicking a row toggles an inline expansion below the row (not a separate modal)
- Expanded content: `bg-brand-surface-raised` background, `px-4 py-3`, `font-mono text-xs text-brand-text` for response body
- JSON formatting: response body is `<pre>` with `whitespace-pre-wrap break-all`, content is `JSON.stringify(parsed, null, 2)`
- Method badge: `GET` in `text-brand-muted`, `POST` in `text-brand-text-secondary`, error status (4xx/5xx) in `red-400`
- Status code: green-400 for 2xx, yellow-400 for 3xx, red-400 for 4xx/5xx
- Sort order: newest first (matches AuditDb.get_all() DESC order — no sort toggle needed)
- Close button: top-right, `w-8 h-8`, same style as TicketDetailPanel close button

### AppShell Navigation Extension

- "Ignored" tab: added alongside existing navigation, same visual weight as gear icon actions
- Navigation style: horizontal tab row below the header bar, `text-sm`, active tab uses `text-brand-text font-semibold border-b-2 border-brand`, inactive uses `text-brand-muted hover:text-brand-text border-b-2 border-transparent`
- Tab labels: "Tickets" (existing candidate list), "Ignored"

### Footer Status Bar

- Position: fixed at the bottom of the app window, inside `AppShell`, above no other element
- Height: 28px (`py-1.5` + `text-xs` single line)
- Background: `brand-surface` with `border-t border-brand-border`
- Content: left-aligned `text-xs text-brand-muted`, format: `{N} API calls`
- Interaction: entire footer bar is clickable, opens AuditLogPage
- Hover: `hover:text-brand-text transition-colors duration-150`
- No icon — plain text link only, developer-tools feel (source: CONTEXT.md D-09)

## Interaction Contracts

### Ignore action (TRIA-01)

- Trigger: "Not Mine" button in TicketDetailPanel header (already exists in code)
- Behavior: instant, no confirmation dialog (source: CONTEXT.md D-02)
- Post-action: ticket disappears from candidate list immediately (source: CONTEXT.md D-03)
- Panel behavior after ignore: close the detail panel and return focus to the ticket list (Claude's discretion — cleaner than leaving an empty panel open)
- TriageIndicator update: row shows "Not mine" pill (`brand-surface-hover` bg, `brand-muted` text) before disappearing on next render cycle

### Un-ignore action (TRIA-03)

- Trigger: "Un-ignore" button in the rightmost column of IgnoredTicketsPage table row
- Behavior: instant, no confirmation dialog (consistent with ignore action)
- Post-action: ticket disappears from ignored list immediately, returns to candidate list with `seen` state
- Button label: "Restore" (verb + implicit noun, matches conversational tone)

### Audit log navigation (AUDIT-02)

- Footer click: replaces main content area with AuditLogPage (same pattern as SettingsPage)
- AuditLogPage close: "Close" button top-right returns to previous view (Tickets or Ignored page)
- Row expand: single click toggles expansion inline; clicking the same row again collapses it
- Only one row expanded at a time — expanding a new row collapses the previous

### AppShell navigation

- "Tickets" tab: shows TicketListPage (candidate tickets)
- "Ignored" tab: shows IgnoredTicketsPage
- Active tab: bottom border accent, semibold weight
- Navigation is top-level — switching tabs does NOT close an open detail panel (detail panel is per-page state)
