## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (`gap-1`), triage indicator dot margins |
| sm | 8px | Inline element spacing (`gap-2`), badge padding (`px-2 py-1.5`) |
| md | 16px | Default element spacing (`gap-4`), form field spacing (`space-y-4`) |
| lg | 24px | Section padding (`px-6`), content regions |
| xl | 32px | Layout horizontal padding (`py-8`) |
| 2xl | 48px | Empty-state vertical padding (`py-16` = 64px, nearest 2xl is 48px — see exception) |
| 3xl | 64px | Page-level vertical spacing |

Exceptions:
- `py-2.5` (10px) on primary buttons — matches existing button pattern in ConnectionForm.tsx; kept for touch target consistency
- `py-16` (64px) on empty state — matches existing SettingsPage empty state pattern
- Table row height: `py-3 px-4` per row (12px / 16px) — dense scan layout for ticket list
- Touch target minimum: 36px × 36px for icon-only buttons (established in AppShell: `w-9 h-9`)

## Typography

| Role | Size | Weight | Line Height | Tailwind | Usage |
|------|------|--------|-------------|----------|-------|
| Body | 14px | 400 (normal) | 1.5 | `text-sm` | Table cells, description text, tab content |
| Label | 12px | 500 (medium) | 1.4 | `text-xs font-medium` | Meta fields, timestamps, attachment sizes, triage badges |
| Heading | 18px | 600 (semibold) | 1.2 | `text-lg font-semibold` | Panel section heading ("Ticket Detail"), settings section headers |
| Display | 20px | 600 (semibold) | 1.2 | `text-xl font-semibold` | Ticket summary (large, prominent in detail panel header) |

Rules:
- Body line-height 1.5 (prose content in description, comments, work log)
- Heading and display line-height 1.2 (single-line labels and titles)
- Column headers in table: `text-xs font-medium text-slate-500` (12px / 500)
- Ticket key (e.g. PROJ-123): `text-xs font-medium text-slate-400` — monospace-adjacent, not italic
- Sortable column header active state: `text-slate-300` (lightened from `text-slate-500`)

## Color

| Role | Value | Tailwind Class | Usage |
|------|-------|----------------|-------|
| Dominant (60%) | #020617 (slate-950) | `bg-slate-950` | App background, main surface |
| Secondary (30%) | #0f172a / 60% opacity (slate-900) | `bg-slate-900/60` | Cards (ticket rows, detail panel, settings cards), sidebar |
| Accent (10%) | #2563eb (blue-600) | `bg-blue-600`, `text-blue-400` | See reserved list below |
| Destructive | #f87171 (red-400) | `text-red-400`, `bg-red-400` | Error messages, failed fetch indicator |
| Success | #34d399 (emerald-400) | `bg-emerald-400` | Copied ticket green checkmark indicator |
| New-ticket | #60a5fa (blue-400) | `bg-blue-400` | New/unseen ticket blue dot indicator |
| Muted | #334155 (slate-700) | `text-slate-500`, `text-slate-600` | Placeholder text, secondary meta, inactive states |

Accent (`blue-600` / `blue-400`) reserved for:
- Primary CTA button background (`bg-blue-600 hover:bg-blue-500`)
- Edit link hover state (`hover:text-blue-400`) — as in ConnectionCard
- Focus ring on inputs (`focus:ring-blue-500/40 focus:border-blue-500/50`)
- Active sort column header indicator
- Triage "new" dot indicator (`bg-blue-400`)
- Active tab underline in detail panel

Accent is NOT used for: general text, headings, card borders, inactive navigation, or table row hover states.

Triage state color map:
- New/unseen: `bg-blue-400` dot (6px circle, left of row)
- Seen: no indicator (normal row styling)
- Copied: `text-emerald-400` checkmark icon (16px inline SVG)

Panel border: `border-slate-800` (consistent with existing cards). Panel background: `bg-slate-900` (full opacity, not 60%, to create visual separation from list underneath).

## Layout Contract

### TicketListPage — Split View

```
┌─────────────────────────────────────────────────────────┐
│ AppShell header (px-6 py-3, border-b border-slate-800)  │
├──────────────────────────┬──────────────────────────────┤
│  Ticket List (flex-1)    │  Detail Panel (~45% width)   │
│  ─ FetchBar (px-6 py-4)  │  (slides in from right)      │
│  ─ TicketTable           │  (hidden when no selection)  │
│    (full height, scroll) │                              │
└──────────────────────────┴──────────────────────────────┘
```

- Outer container: `flex h-screen overflow-hidden` (fills viewport below header)
- Ticket list pane: `flex-1 flex flex-col overflow-hidden` (takes remaining width)
- Detail panel: `w-[45%] border-l border-slate-800 bg-slate-900 flex flex-col` — fixed width when open, `hidden` (or `w-0 overflow-hidden`) when closed
- Panel slide animation: `transition-all duration-200 ease-in-out` on width (200ms — matches existing transition durations in project)
- No resizable split in Phase 3 — fixed 55/45 proportions

### Loading State — Table Skeleton

When `fetchStatus === 'loading'`:
- Show 8 skeleton rows (8 covers 5-20 typical batch with visual breathing room)
- Skeleton row: `animate-pulse` with placeholder bars — `bg-slate-800/60 rounded h-3` at appropriate widths per column
- FetchBar button: disabled, shows spinner + "Fetching..."

### Error State — Failed Fetch

When `fetchStatus === 'error'`:
- Inline below FetchBar, NOT a modal
- Container: `mx-6 mt-3 rounded-lg border border-red-400/20 bg-red-400/5 px-4 py-3`
- Error text: `text-sm text-red-400`
- Sub-text: `text-xs text-slate-500 mt-0.5`
- No retry button in the error banner — the "Fetch Tickets" button itself is the retry (re-enabled after error)

### Empty State — No Tickets Returned

When fetch succeeds but returns 0 results:
- Centered in the table area: `flex flex-col items-center justify-center flex-1 py-16`
- Heading: `text-sm font-medium text-slate-400 mb-1`
- Body: `text-xs text-slate-600`

### Lazy Loading (Work Log / History Tabs)

On tab click (first open):
- Show 3 skeleton rows (`animate-pulse bg-slate-800/60 rounded h-3 mb-2`)
- Invoke Tauri command, replace skeleton with real data or inline error message

## Accessibility

- All interactive elements: minimum 36×36px touch target (established `w-9 h-9` pattern)
- Sort headers: `role="columnheader" aria-sort="ascending|descending|none"`
- Table: `role="table"` with `role="row"`, `role="rowheader"`, `role="cell"`
- Selected row: `aria-selected="true"`, `aria-pressed` on the row button
- Detail panel: `role="complementary" aria-label="Ticket detail"` — or `role="region"`
- Tabs: `role="tablist"`, `role="tab"`, `role="tabpanel"`, `aria-selected`, `aria-controls`
- Loading states: `aria-busy="true"` on containing region, `aria-live="polite"` on summary line
- Error regions: `role="alert"` on error banners
- Skeleton rows: `aria-hidden="true"` — decorative only
- Focus management: when panel opens, move focus to close button; when panel closes, return focus to originating row
- Keyboard nav: `Enter` or `Space` on row opens panel; `Escape` closes panel; `Tab` cycles through panel tabs
