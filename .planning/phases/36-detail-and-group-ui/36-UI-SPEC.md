# Phase 36 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** Wiring of explicit labelled Deny / Link / Restore buttons in the shared ticket detail (page, panel, group view via the same detail), the remembered-link hint, focus handling, and EN/SK strings. No new screens, no new colors, no new tokens. All handlers call `src/features/tickets/triageActions.ts` (`denyTicket`, `linkTicket`, `restoreTicket`); no inline `set_triage_state` writes. Deny Undo toast and error toasts already exist from Phase 35 (`triage.*` keys) and are unchanged.

Sources: CONTEXT.md D-01..D-07 (locked), 35-UI-SPEC.md (tokens, toast), existing `TicketDetailPanel.tsx` action row (L216-350), `GroupViewPage.tsx` row (L150-180). Items marked (default) were delegated and chosen here.

## Interaction Contract

### Detail action row (page and panel; group view reuses the shared detail)

Order is left to right in the existing `flex items-center gap-2` row. Implementation should extract the shared button set so page and panel do not diverge, but visual output is identical.

| Ticket state | Row contents |
|--------------|--------------|
| New (unchanged) | Open in Jira, Dismiss, Mark handled, Copy (primary) |
| Handled (unchanged) | Open in Jira, Handled (toggle restore) |
| **Linked** (`copied` with `copiedKey`) | Linked badge `Copied → KEY`, `·`, source Jira link, `·`, Cloud key link, **Deny** (neutral outlined, after the Cloud-key link) (D-02, D-03 default) |
| **Denied** (`ignored`) with remembered key | Open in Jira, **Restore link to KEY** (primary accent), **Restore** (neutral outlined, to "seen") |
| **Denied** (`ignored`) never linked | Open in Jira, **Link** with existing copy wording `Copy to {project}` (primary, existing `detail.copy`), **Restore** (neutral) |

- The toggle-like "Ignored" button (`detail.ignored`) is replaced by the explicit **Restore** button in the denied state. Tooltips on these buttons are supplementary only and `aria-hidden`; the label carries all meaning.
- Deny: `onClick` -> `denyTicket(key)` (optimistic, shows Phase 35 Undo toast). No confirmation dialog.
- Restore link: `onClick` -> `linkTicket(key)`. Result `relinked`: ticket becomes Linked, no toast. Result `needs-copy`: open the existing copy preview exactly as today. Result `failed`: `triage.linkFailed` error toast (existing).
- Restore: `onClick` -> `restoreTicket(key)`; failure uses existing `ignored.restoreFailed` toast.
- Disabled/loading: Link keeps the existing `loading_preview` spinner + `disabled:opacity-50` behavior when it opens the copy preview. While a deny/relink is in flight, the clicked button gets `disabled` to prevent double-submit.
- Buttons are native `<button type="button">`, visible 2px focus ring using the app's existing focus-visible style; minimum height matches the existing `py-1` row (28px). Documented exception to the 44px target: dense desktop action row, consistent with existing buttons.

### Remembered-link hint (RLNK-03, D-04 default)

- Text: "Previously linked to KEY" rendered as plain visible text, never tooltip-only.
- Condition: shown only when the entry is `ignored` and `copiedKey` is set.
- Detail: a `<p className="text-xs text-brand-muted mt-1">` directly under the action row (above `copyError`). Not an interactive element. The key is rendered in `font-mono`.
- Not mine rows (`IgnoredTicketsPage` and the `nav.notMine` branch in `GroupViewPage`): inline `<span className="text-xs text-brand-text-secondary">` placed in the existing `actionSlot` before the Restore button, same muted style as the existing linked-key chip. Row text does not wrap awkwardly: key is `font-mono`, whole span `whitespace-nowrap`.
- No hover-revealed content anywhere.

### List rows (D-06 default)

Detail-only for Deny and Link. Rows keep the existing text Restore button and gain the hint above. No new row icons or buttons.

### Focus management (RTRI-04, D-05 default)

Focus must never fall to `<body>` when a button unmounts. Use a ref and focus after the state change renders (effect keyed on the triage state, not a timeout).

| Action | Focus target |
|--------|--------------|
| Deny succeeds (Deny unmounts, denied row renders) | The primary denied-state button (Link / "Restore link to KEY"; or `Copy to...` when never linked) |
| Link restore -> `relinked` (Link unmounts, Linked row renders) | The Linked status badge container made programmatically focusable (`tabIndex={-1}`, `outline-none`), fall back to the Deny button if the badge ref is missing |
| Restore -> seen (denied buttons unmount) | The Dismiss button of the New state (first neutral action); in the panel, fall back to the close button |
| Link `needs-copy` | Unchanged: copy preview owns focus |
| Undo from toast | Not managed here (Phase 37 covers announcements) |

If the Deny IPC fails (optimistic rollback), focus stays on the Deny button. Panel's existing "focus close button on load" is kept. WebView2 verification belongs to the Phase 37 checklist; this phase only guarantees the code path.

### Group view

No separate implementation: opening a ticket from `GroupViewPage` renders the shared detail, so it inherits all of the above. Group row Not mine branch gets the hint only.

### Constraints (project feedback)

No drag and drop; no hover-revealed icons; one entry point per action in detail; no Jira call on Deny; Zustand selectors must not return `?? []` (use `null` fallback when selecting `triageMap[key]`).

## Copywriting Contract

All keys added to both `src/i18n/locales/en.json` and `sk.json`. Slovak uses "tiket", never "úloha" (groups guard test enforces). Reuse existing `ignored.restore` ("Restore" / "Obnoviť"), `detail.copy`, `triage.*`.

| Element | Key (proposal) | EN | SK |
|---------|----------------|----|----|
| Deny button | `detail.deny` | Deny | Zamietnuť |
| Deny tooltip (supplementary) | `detail.deny.tooltip` | Move this ticket to Not mine. The link to KEY is remembered, and you can undo this. | Presunie tiket medzi Nie moje. Prepojenie sa zapamätá a môžete to vrátiť späť. |
| Restore link button (D-01) | `detail.restoreLink` | Restore link to {{key}} | Obnoviť prepojenie s {{key}} |
| Restore link tooltip | `detail.restoreLink.tooltip` | Link this ticket to {{key}} again. No new Jira issue is created. | Znova prepojí tiket s {{key}}. Nevytvorí sa nový Jira tiket. |
| Restore to seen button | reuse `ignored.restore` | Restore | Obnoviť |
| Remembered-link hint | `detail.previouslyLinked` | Previously linked to {{key}} | Predtým prepojené s {{key}} |
| Row hint | reuse `detail.previouslyLinked` | Previously linked to {{key}} | Predtým prepojené s {{key}} |
| Primary CTA (this phase) | - | Restore link to {{key}} (denied with link); Copy to {project} (never linked) | as above |
| Empty state | - | not applicable (no new screens) | - |
| Error: deny / link / restore | reuse | `triage.denyFailed`, `triage.linkFailed`, `ignored.restoreFailed` | existing |
| Destructive confirmation | - | none: Deny is undoable via toast and Restore; no Cloud delete | - |

Terminology note for planner: existing EN strings are inconsistent ("Dismissed" tab via `nav.notMine`, "Ignored" in `triage.denied`). New strings above say "Not mine" per the ROADMAP; the tab label itself is not renamed in this phase. If the planner prefers zero drift, replace "Not mine" in the tooltip with the interpolated `t('nav.notMine')`. SK tooltip should likewise use the existing `nav.notMine` SK value rather than the literal if it differs. Add both key sets to the i18n guard tests' expected-key parity.
