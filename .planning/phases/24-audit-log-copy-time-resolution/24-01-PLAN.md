<objective>
Add a copy-time per-field audit loop to `copy_ticket_v2` in commands.rs so the `mapping_audit_log` table contains actual `apply_mapping` resolution outcomes for `wiki_to_adf` and `user` fields — not just the preview-time prefill snapshot. Purpose: Users currently see `target: null / skipped` for every async-resolution field in the audit tab after copying. This is the preview-time prefill log. The actual resolved values are never written. This plan closes that gap.

- `CopyTicketV2Args` gains `copy_id: Option<String>`

- `copyStore.confirmCopy` passes `copyId: previewCopyId` in the invoke args
- `CopyPreviewPage.handleConfirm` threads `previewCopyId` to `confirmCopy`
- A Rust unit test in `commands.rs` test module verifies rows are written with correct outcomes

   The full block to insert:
   ```rust
   // Phase 24 — Copy-time audit entries written AFTER override merge so
   // resolved.fields contains the final values actually sent to Jira Cloud.
   // Best-effort: per-row and transaction errors are swallowed so an audit
   // hiccup never blocks the copy operation.
   {
       let copy_id = args.copy_id.clone().unwrap_or_else(|| {
           uuid::Uuid::new_v4().to_string()
       });
       let timestamp = chrono::Utc::now().to_rfc3339();
       let mdb = mapping_db
           .lock()
           .map_err(|_| AppError::Internal("FieldMappingDb lock poisoned".into()))?;
       let _ = mdb.begin_transaction();
       for row in &mapping_rows {
           if row.target_field_id.is_empty() {
               continue;
           }
           let src_path = format!("/fields/{}", row.source_field_id);
           let src_val = source_body.pointer(&src_path).cloned().unwrap_or(serde_json::Value::Null);
           let tgt_val = resolved
               .fields
               .get(&row.target_field_id)
               .cloned()
               .unwrap_or(serde_json::Value::Null);

           let (outcome, gap_kind, failure_reason): (&str, Option<&str>, Option<&str>) =
               if !tgt_val.is_null() {
                   ("copied", None, None)
               } else if src_val.is_null() {
                   ("skipped", None, Some("source value missing"))
               } else {
                   let gap = resolved.gaps.iter().find(|g| match g {
                       crate::field_transform::GapVariant::Person(p) => {
                           p.target_field_id == row.target_field_id
                       }
                       crate::field_transform::GapVariant::Version(v) => {
                           v.target_field_id == row.target_field_id
                       }
                       crate::field_transform::GapVariant::Component(c) => {
                           c.target_field_id == row.target_field_id
                       }
                   });
                   match gap {
                       Some(crate::field_transform::GapVariant::Person(_)) => {
                           ("failed", Some("person"), Some("user not resolved"))
                       }
                       Some(crate::field_transform::GapVariant::Version(_)) => {
                           ("failed", Some("version"), Some("version not resolved"))
                       }
                       Some(crate::field_transform::GapVariant::Component(_)) => {
                           ("failed", Some("component"), Some("component not resolved"))
                       }
                       None => ("skipped", None, Some("source value missing")),
                   }
               };

           let was_overridden = args.override_values.contains_key(&row.target_field_id);
           let src_red = redact_string_in_value(&src_val);
           let tgt_red = redact_string_in_value(&tgt_val);
           let src_hash = hash_field_value(&src_red);
           let tgt_hash = hash_field_value(&tgt_red);
           let src_json = serde_json::to_string(&src_red).ok().map(cap_audit_json);
           let tgt_json = serde_json::to_string(&tgt_red).ok().map(cap_audit_json);
           let _ = mdb.insert_mapping_audit(
               &copy_id,
               &row.target_field_id,
               &src_hash,
               &tgt_hash,
               was_overridden,
               gap_kind,
               &row.transformer_kind,
               outcome,
               failure_reason,
               &timestamp,
               src_json.as_deref(),
               tgt_json.as_deref(),
           );
       }
       let _ = mdb.commit_transaction();
   }
   ```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend args → copy_ticket_v2 | copyId is frontend-provided; treated as unvalidated string |
| resolved field values → audit DB | Raw JSON from apply_mapping; must be redacted and capped before persistence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-24-01 | Tampering | copy_id field in CopyTicketV2Args | accept | copy_id is a UUID used only for grouping audit rows; it is never executed or used as a key for access control; a spoofed UUID would merely group rows under a different ID — no security impact |
| T-24-02 | Information Disclosure | copy-time audit rows persisting field values | mitigate | `redact_string_in_value` applied to both source and target values before hash or JSON persist; same control already active in `log_preview_transformations` — reuse identical code path |
| T-24-03 | DoS | unbounded JSON values in audit rows | mitigate | `cap_audit_json` at 4096 bytes applied to src_json and tgt_json before INSERT — same cap used in existing audit path; `mapping_rows` length bounded by mapping table size (no attacker control) |
| T-24-04 | Tampering | SQL injection via row.target_field_id or copy_id | accept | `insert_mapping_audit` uses `params![]` binding — SQL injection test already exists in field_mapping_db.rs:1116; no change to the binding layer |
</threat_model>
