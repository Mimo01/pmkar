## Review advisories (37.2-REVIEW.md)

- **WR-02** (Restore from Watched with remembered key goes to New, not Linked): consistent with the requirement and UAT test 7. WATCH-03 gives Watched a separate "Restore link to KEY" button and a plain Restore to New, so the goal is met. It is a UX-clarity note. Warning only.
- **WR-01** (migration not atomic; the detection error is swallowed): real robustness risk. In the normal path the rebuild succeeds and the tests pass. A mid-batch failure would leave a transaction open, and a migration failure on a real legacy DB is covered by UAT test 10. Not goal-blocking. Recommended follow-up: use `unchecked_transaction`, add `DROP TABLE IF EXISTS triage_state_new`, and propagate the `query_row` error.
- **WR-03** (`undoWatch` staleness check is state-only; dead `copied` branch): harmless, since the toast id is replaced on re-watch and the branch is unreachable. Warning only.
