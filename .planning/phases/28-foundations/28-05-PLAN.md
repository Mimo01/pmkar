## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-28-14 | Spoofing / Information Disclosure | scope selection | mitigate | No command accepts a scope argument; `resolve_scope` derives it from server connection_meta (acceptance grep checks no `scope` param on commands) |
| T-28-15 | Tampering | command arguments | mitigate | All validation delegated to GroupsDb (name rules, color whitelist, issue key shape, JSON object check); serde rejects malformed `direction` |
| T-28-16 | Denial of Service | deadlock between triage and groups mutexes | mitigate | resolve_scope releases triage lock in a scoped block before lock_groups; `try_lock` test asserts release (D-21) |
| T-28-17 | Denial of Service | poisoned mutex panic | mitigate | Poison mapped to `{code:"internal"}`; tested |
| T-28-18 | Information Disclosure | error messages over IPC | accept | Internal errors carry the rusqlite/AppError display string only (no ticket_json, no credentials); local single-user app |
