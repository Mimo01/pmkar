  <action>
Create `src/features/groups/useListSelection.ts` implementing the `ListSelection` contract, using React `useState` local to the calling page (no Zustand, per PITFALLS "Selection leakage").

State and memoized values:
- `selectMode` (boolean)
- `selected` (a `Set<string>`, replaced immutably on change)
- `anchor` (`string | null`)
- `selectedKeys`, memoized as `visibleKeys.filter((k) => selected.has(k))`

`toggle(key, shift)` follows the range anchor rule (Claude's Discretion, documented here):
- If `shift && anchor !== null` and both anchor and key are in `visibleKeys`, ADD every key from `min(idx)` to `max(idx)` inclusive to the selection.
- Otherwise flip the key's membership.
- In both cases, then set `anchor = key`.

Prune: a `useEffect` on `visibleKeys` that removes selected keys not in `visibleKeys`, and resets `anchor` if it is not visible. Only call setState when something actually changes. Compare by content: build the next set and bail out if its size equals the current size. This prevents the loop warned about in RESEARCH Pattern 2.

The remaining contract functions:
- `toggleSelectMode()`: when turning off, also clear the selection and anchor.
- `exit()`: sets mode off, clears the selection, and sets anchor to null.
- `clear()`: clears the selection and anchor but keeps the mode.
- `selectToggleRef`: created with `useRef<HTMLButtonElement | null>(null)`.
- `focusSelectToggle()`: uses a local copy of the GroupTabStrip `afterUnmount` idiom (requestAnimationFrame when available, else `setTimeout(fn, 0)`) to call `selectToggleRef.current?.focus()`.
- `handleKeyDown(e)`: if `e.key === 'Escape' && !e.defaultPrevented && selectMode`, call `e.preventDefault()`, `exit()` and `focusSelectToggle()`. The `defaultPrevented` guard relies on Radix DismissableLayer calling preventDefault on Escape before React's root listener runs (RESEARCH A2, OQ4). Plans 06, 08 and 09 cover this with explicit popover tests.

Wrap the functions in `useCallback` and return a `useMemo` object so consumers can pass it as stable props. Do not add any select-all function (D-13).
