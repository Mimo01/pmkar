## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-31-08 | Tampering | Create row name input | mitigate | `validateGroupName` runs before submit (TS mirror). Rust re-validates authoritatively (Phase 28 D-16). Rust error codes are shown inline |
| T-31-09 | Spoofing | Bidi or invisible characters in group names in rows | mitigate | Names render as React text children only (no dangerouslySetInnerHTML, enforced by an acceptance grep). Rust normalisation strips controls |
| T-31-10 | Tampering | Color style injection | mitigate | Dot color only via `groupColorVar(g.color)`. `load()` already coerces tokens with `isGroupColorToken` |
