**Schema constant:**
```rust
const CREATE_SNAPSHOT_TABLE: &str = "
    CREATE TABLE IF NOT EXISTS snapshot_store (
        ticket_key      TEXT PRIMARY KEY,
        response_json   TEXT NOT NULL,
        content_hash    TEXT NOT NULL,
        last_checked_at TEXT NOT NULL
    );
";
```

**Types:**
- `StoredSnapshot` struct with fields: `response_json: String`, `content_hash: String`, `last_checked_at: String`. Derive `Debug, Clone`.
- `FieldChange` struct with fields: `field: String`, `old_value: Option<String>`, `new_value: Option<String>`. Derive `Debug, Clone, Serialize, Deserialize` with `#[serde(rename_all = "camelCase")]` (per D-07).
- `SnapshotDb` struct with field `conn: Connection`.

**SnapshotDb methods:**
- `pub fn open(path: &std::path::Path) -> AppResult<Self>` — opens file-backed SQLite, runs CREATE_SNAPSHOT_TABLE.
- `pub fn open_in_memory() -> AppResult<Self>` — opens in-memory SQLite, runs CREATE_SNAPSHOT_TABLE (per research Pitfall 5).
- `pub fn store_snapshot(&self, ticket_key: &str, response_json: &str) -> AppResult<String>` — computes hash via `compute_hash`, stores with INSERT OR REPLACE using `ON CONFLICT(ticket_key) DO UPDATE SET`, sets `last_checked_at` to `chrono::Utc::now().to_rfc3339()`. Returns the hash string.
- `pub fn get_snapshot(&self, ticket_key: &str) -> AppResult<Option<StoredSnapshot>>` — SELECT by ticket_key, returns None on QueryReturnedNoRows.
- `pub fn get_watermark(&self) -> AppResult<Option<String>>` — `SELECT MIN(last_checked_at) FROM snapshot_store`. Returns None when table is empty (per D-09).

**Hash computation (private functions):**
- `fn compute_hash(response_json: &str) -> AppResult<String>` — parse JSON to `serde_json::Value`, call `strip_volatile_fields`, serialize stripped value with `serde_json::to_string`, SHA-256 hash, hex encode (per D-03).
- `fn strip_volatile_fields(mut v: serde_json::Value) -> serde_json::Value` — strips keys: `"self"`, `"expand"`, `"avatarUrls"`, `"iconUrl"`, `"48x48"`, `"32x32"`, `"24x24"`, `"16x16"` recursively through all objects and arrays (per D-03).
- `fn strip_recursive(v: &mut serde_json::Value, keys: &[&str])` — recursive helper that removes keys from objects and recurses into arrays.

**Change detection (public functions):**
- `pub fn detect_changes(old_json: &str, new_json: &str) -> AppResult<Vec<FieldChange>>` — parses both JSON strings, walks WATCHED_FIELDS comparing extracted string values, checks comment count delta at `/fields/comment/comments` array length, checks attachment count delta at `/fields/attachment` array length, checks worklog count delta at `/fields/worklog/worklogs` array length (per D-05, D-06).
- `fn extract_string(value: &serde_json::Value, pointer: &str) -> Option<String>` — uses `value.pointer(pointer)` and converts to string (for objects/arrays, use `serde_json::to_string`; for strings, use `.as_str()`; for numbers, use `.to_string()`).
- `fn count_array(value: &serde_json::Value, pointer: &str) -> usize` — uses pointer to get array, returns `.len()` or 0 if not found.

**WATCHED_FIELDS constant:**
```rust
const WATCHED_FIELDS: &[(&str, &str)] = &[
    ("status",       "/fields/status/name"),
    ("priority",     "/fields/priority/name"),
    ("assignee",     "/fields/assignee/displayName"),
    ("summary",      "/fields/summary"),
    ("description",  "/fields/description"),
    ("labels",       "/fields/labels"),
    ("components",   "/fields/components"),
    ("fix_versions", "/fields/fixVersions"),
];
```

**Top-level orchestrator:**
- `pub fn check_for_changes(snap_db: &SnapshotDb, ticket_key: &str, new_json: &str) -> AppResult<Vec<FieldChange>>` — computes new hash, calls `get_snapshot`: if None (first time), stores and returns empty vec; if hash matches (per D-04), stores and returns empty vec; if hash mismatch, runs `detect_changes` on old vs new JSON, then stores new snapshot, returns changes.
