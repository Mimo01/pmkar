## Where search lives

| Option | Description | Selected |
|--------|-------------|----------|
| Header box + dropdown | Always-visible header field, results dropdown | ✓ |
| Dedicated Search page | New nav item with a full-page table | |
| Ctrl/Cmd+K palette | Modal command palette | |

Per-tab filter: **Keep it, widen to summary** (other options: keep key-only, remove).
Shortcut: **Ctrl/Cmd+K and Ctrl/Cmd+F** (other options: K only, none).

## Searchable fields & data

| Option | Description | Selected |
|--------|-------------|----------|
| Local, add description to fetch | Instant, offline, no comments | ✓ |
| Local + remote JQL fallback | Plus a "search customer Jira" action | |
| Remote JQL only | Every search hits the server | |

Fields: key, summary, description, assignee, labels/components/fix versions, linked Cloud key (all selected).
Scope: **all known tickets, including snapshot-only group members**.
Side effects: **silent upgrade, description never tracked as a change** (other option: track edits after upgrade).

## Results & opening a hit

Row: **category badge + group chips** (other options: badge only, sectioned).
Open: **ticket detail, Back returns** (other option: jump to tab).
Limit: **top 20 + "N more" note** (other option: all, scrollable).
Keyboard: **combobox pattern** (other option: Tab through buttons).
Empty: **"No tickets match" + hint** (other option: minimal).

## Matching rules

Match: **all words, any order** (other option: exact phrase).
Diacritics: **ignored both ways** (other option: exact).
Ranking: **key > summary > other, then updated** (other option: updated only).
Display: **highlight, start at 2 chars** (other option: no highlight, 1 char).
