<objective>
Build the presentational pieces of a search result: the `<mark>` highlighter and the option row.

Purpose: D-08, D-16 and the UI-SPEC result row contract, plus project chip rules (tinted, no tooltips) and row rules (explicit actions only, no hover icons).
Discretion choices recorded here:
- UserAvatar uses size `sm` (20px). The component only has `sm`/`md`, and the UI-SPEC "xs" is not worth a new size.
- Badge labels use the dedicated `search.badge.*` keys from plan 03.
- Chips are built from `GroupChipLabel` + `groupChipClass` + `groupColorStyle` in a `<span>` instead of `GroupChips`/`CardGroupChip`, which are navigation buttons.
- Translation calls use literal keys only (switch statements), so the noLiteralStrings dynamic-key allowlist does not need entries.
Output: two components and two test files.
</objective>
