Create `GlobalSearch({ onOpenTicket }: { onOpenTicket: (key: string) => boolean })`.

State:
- `query`/`setQuery`/`clearQuery` from useSearchStore (D-09).
- Local `debounced`, initialized to the store query. The useEffect setTimeout uses SEARCH_DEBOUNCE_MS and clears on change.
- Local `open` (false initially, so it never auto-opens on remount), `active` (-1) and `activated` (false; set true on first focus or input).
- `const { items, ready } = useSearchCorpus(activated)`.
- `const result = useMemo(() => searchTickets(items, debounced), [items, debounced])`.
- `panelVisible = open && ready && debounced.trim().length >= SEARCH_MIN_CHARS`.
- Ids come from `useId()`: listbox `${id}-listbox` and option `${id}-opt-${i}`.
- Reset active to -1 whenever result changes.

Handlers:
- onChange: setQuery, activated true, `open = value.trim().length >= SEARCH_MIN_CHARS`.
- onFocus: activated true, and open when the stored query trim is at least 2.
- onKeyDown, mirroring TicketFilterBar:
  - ArrowDown/ArrowUp: preventDefault and wrap. When closed but the query is at least 2, open first.
  - Home/End: only when panelVisible, with preventDefault.
  - Enter: index = active >= 0 ? active : (hits.length ? 0 : -1). If index >= 0, preventDefault, and when `onOpenTicket(hits[index].item.ticket.key)` returns true, set open false and active -1.
  - Escape: if panelVisible, preventDefault and close. Else if query is non-empty, preventDefault, clearQuery and set debounced ''. Else do nothing (propagates).
  - Tab: close without preventDefault.
- Scroll the active option into view with `document.getElementById(optId)?.scrollIntoView?.({ block: 'nearest' })`.
- Click outside: a document mousedown listener closes when the target is outside the wrapper ref.
- Call `useSearchShortcut(inputRef)`.

Announcement: an effect keyed on `[result, ready, debounced]` that skips the first run after mount (ref) and runs only when the trimmed debounced value is at least 2 and ready. It calls `announce(result.total === 0 ? t('search.live.none') : t('search.live.count', { count: result.total }))`. Never announce on selection.

Markup (UI-SPEC):

- Right slot: when the query is non-empty, a clear button (`X` icon, aria-label={t('search.clear')}, focus-visible ring-brand, 24px hit area). Otherwise `<kbd aria-hidden="true" className="text-xs text-brand-text-secondary border border-brand-border rounded px-1">{shortcutHint()}</kbd>`.
- Panel when panelVisible: `<div className="absolute left-0 top-full mt-1 w-[560px] max-w-[calc(100vw-32px)] max-h-[480px] overflow-y-auto z-50 rounded-md border border-brand-border bg-brand-surface shadow-lg">`.
  - Hits present: `<ul role="listbox" id aria-label={t('search.listLabel')}>` of SearchResultRow with onSelect -> open hit and onHover -> setActive(i).
  - `result.total > result.hits.length`: footer `<div className="px-4 py-2 border-t border-brand-border text-xs text-brand-text-secondary">{t('search.footer.truncated', { shown: result.hits.length, total: result.total })}</div>`.
