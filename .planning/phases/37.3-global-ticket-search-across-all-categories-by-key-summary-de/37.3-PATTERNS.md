
**Combobox keyboard + Esc consume** (L117-137). Copy shape; extend with Home/End, wrap-around, Enter-with-no-active opens first, Tab closes, and second-Esc clears:
```typescript
if (e.key === 'ArrowDown') { e.preventDefault(); setSelectedIdx((i) => Math.min(i + 1, suggestions.length - 1)); }
```

The `preventDefault` on Escape is load-bearing: `TicketDetailPage.tsx:112-118` has a `document` Escape listener that calls `onBack()` unless `e.defaultPrevented`. Add a test: Esc in search on detail page does not call `onBack`.

## Shared Patterns

### Zustand selector safety
**Source:** `useGroupMembers.ts:81`. Use `?? null`, never `?? []` in selectors. Applies to `useSearchCorpus`, `GlobalSearch`.

### i18n and announcer guards
**Source:** `noLiteralStrings.test.ts` L14-42, `LiveAnnouncer.tsx`. All user-facing strings via `t()`; announcements via `announce(t(...))`.

### Escape handling inside nested interactive widgets
**Source:** `TicketFilterBar.tsx:132-136` and `TicketDetailPage.tsx:108-122`. Handled Esc must `e.preventDefault()`.

### Triage category derivation
**Source:** `ticketListUtils.ts:12-56` (`isNewCandidate`, `isNotMineCandidate`, `isLinkedCandidate`, `isWatchedCandidate`). Single source of truth; Done tickets match none.

### Snapshot shape validation
**Source:** `useGroupMembers.ts:14-37` `isRenderableTicket`. Apply to every parsed snapshot in `useSearchCorpus`.

### Style rules (project memory + UI-SPEC)
No drag and drop, no hover-revealed row actions, no row restore buttons, no `text-brand-muted` on text (decorative icons only), no `brand-accent`, group chips have no tooltips, SK says "tiket".
