**TicketCard.tsx — outer clickable element:**

The outer `<div onClick={onClick}>` must become keyboard-accessible. Use `<div role="button">` pattern (NOT `<button>`) because `actionSlot` can contain nested `<button>` elements (e.g., Restore button in IgnoredTicketsPage), and nested `<button>` inside `<button>` is invalid HTML.

Change the outer div to:
```tsx
<div
  onClick={onClick}
  onKeyDown={(e) => { if (e.key === 'Enter' || e.key === ' ') { e.preventDefault(); onClick(); }}}
  tabIndex={0}
  role="button"
  aria-label={ticket.fields.summary}
  className="px-4 py-3 cursor-pointer transition-colors duration-150 hover:bg-brand-surface-hover border-b border-brand-border focus-visible:outline-2 focus-visible:outline-brand focus-visible:outline-offset-[-2px]"
>
```

Note: replaced `focus-visible:ring` with `focus-visible:outline` for card items (outline with negative offset avoids ring-offset gap issues on list items).

**PriorityDot — D-02 compliance (per locked decision D-02):**

Currently PriorityDot renders only a color dot with `aria-label` (screen reader only — sighted users see color only). Must add visible priority name text to comply with D-02.

Replace the PriorityDot function body with:
```tsx
function PriorityDot({ priority }: { priority: string }) {
  const lower = priority.toLowerCase();
  let color = 'var(--color-brand-muted)'; // Lowest
  if (lower === 'highest' || lower === 'critical') color = '#dc2626';
  if (lower === 'high') color = '#ea580c';
  if (lower === 'medium') color = '#ca8a04';
  if (lower === 'low') color = '#3b82f6';
  return (
    <span className="flex items-center gap-1">
      <span
        className="w-1.5 h-1.5 rounded-full flex-shrink-0"
        style={{ backgroundColor: color }}
        aria-hidden="true"
      />
      <span className="text-xs text-brand-text-secondary">{priority}</span>
    </span>
  );
}
```

Key changes: dot span gets `aria-hidden="true"` (decorative — text provides meaning), visible `<span>` with priority name text added next to dot. Removed `aria-label` from the dot since the text is now visible.
