## Spacing Scale

Declared values (multiples of 4). The project uses Tailwind v4 utility classes; this table maps token names to their px equivalents.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Picker option row vertical padding, input inner padding |
| md | 16px | Section padding inside renderers, label-to-input gap |
| lg | 24px | Group spacing between renderer rows in DynamicTargetForm |
| xl | 32px | DynamicTargetForm outer padding |
| 2xl | 48px | Not used in Phase 20 renderers |
| 3xl | 64px | Not used in Phase 20 renderers |

Exceptions:
- Touch targets for combobox trigger buttons: 44px minimum height (WCAG 2.5.5 advisory), achieved via `min-h-11` (44px).
- VirtualizedCombobox row height: 36px fixed (`h-9` / 36px) — required by @tanstack/react-virtual for stable row measurement.

## Typography

All sizes are Tailwind v4 utility values mapped to their rem equivalents. Source: existing shadcn components in `src/components/ui/`.

| Role | Size | Weight | Line Height | Tailwind class |
|------|------|--------|-------------|----------------|
| Body / input value | 14px (0.875rem) | 400 regular | 1.5 | `text-sm` |
| Label / field name | 12px (0.75rem) | 500 medium | 1.4 | `text-xs font-medium` |
| UnsupportedType pill | 12px (0.75rem) | 600 semibold | 1 | `text-xs font-semibold` |
| Combobox option row | 14px (0.875rem) | 400 regular | 1.5 | `text-sm` |

Two weights only: regular (400) for all input values and option rows, medium/semibold (500/600) for labels and badges. Source: existing badge uses `font-semibold`, button uses `font-medium`.

## Color

Source: `src/index.css` — brand token definitions used across both light and dark themes.

| Role | Light value | Dark value | Usage |
|------|-------------|------------|-------|
| Dominant (60%) | `#f7f7f8` | `#161617` | Page background, form shell background |
| Secondary (30%) | `#ffffff` | `#1e1e20` | Renderer card surfaces, combobox popover background |
| Accent (10%) | `#c02232` | `#c02232` | Focus ring (`--color-ring`), required-field asterisk indicator |
| Muted text | `#8c8c92` | `#7f7f7f` | Placeholder text inside inputs, "no results" copy |
| Border | `#e0e0e3` | `#2e2e30` | Input borders, combobox trigger borders |
| Destructive | `#dc2626` | `#dc2626` | Not used in Phase 20 (no delete actions) |

Accent (`#c02232`) reserved for:
1. Focus ring on all interactive inputs (via `focus-visible:ring-ring`)
2. Required-field asterisk `*` label suffix (visual indicator only — gating is Phase 22)
3. Nothing else — accent is NOT used for hover states, backgrounds, or selected-item highlighting

Selected combobox item uses `bg-muted` (`--color-muted`, `#f0f0f2` light / `#28282a` dark) — not accent.

## Component Inventory

New components Phase 20 must deliver. Each maps to one renderer file. All follow the `cn()` pattern from `src/lib/utils`.

### VirtualizedCombobox (shared base)

- File: `src/features/field-renderers/components/VirtualizedCombobox.tsx`
- Built on: `cmdk` + `@tanstack/react-virtual`
- `useFlushSync: false` (React 19 compatibility — CONTEXT.md Specifics)
- Row height: 36px fixed
- Overscan: 5 rows
- Trigger: shadcn `Button` variant=outline, full width, displays current selection or placeholder
- Popover: `bg-popover border border-border rounded-md shadow-md`, max-height 320px with scroll
- Search input inside popover: `text-sm`, no border, full width, `pl-8` with search icon (lucide `Search` 14px)
- "No results" row: `text-sm text-muted-foreground py-6 text-center`

### StringRenderer

- Single-line `<input type="text">` using Tailwind `input` pattern
- Classes: `flex h-9 w-full rounded-md border border-input bg-transparent px-3 py-1 text-sm shadow-sm`

### TextAreaRenderer

- Multi-line `<textarea>` for description / wiki fields
- `min-h-[80px]` (80px minimum), resizable vertically only
- Same border and radius as StringRenderer

### UrlRenderer

- `<input type="url">` with a lucide `Link` (14px) prepended icon
- Validates with `pattern="https?://.*"` (HTML5 only — no blocking validation in Phase 20)

### UserPickerRenderer / MultiUserPickerRenderer

- Use `VirtualizedCombobox` with async `onSearch` callback (CONTEXT.md D-01)
- Selected user chip displays `UserAvatar` (reuse `src/features/tickets/UserAvatar.tsx`) + display name
- Debounce: 300ms (matches `TicketFilterBar` pattern — CONTEXT.md code patterns)
- Loading state: lucide `Loader2` spinning, 14px, inside combobox trigger right slot
- `UserPickerRenderer`: single selection, one chip
- `MultiUserPickerRenderer`: multiple chips in a wrapping flex row, each chip removable with an inline `X` (lucide `X` 12px)

### GroupPickerRenderer

- `VirtualizedCombobox` with static `allowedValues`
- Items display as plain text (no avatar)

### SingleSelectRenderer

- `VirtualizedCombobox` with static `allowedValues`, single selection
- Option rows show label text only

### MultiSelectRenderer

- `VirtualizedCombobox` with static `allowedValues`, multi-selection
- Selected items appear as `Badge` (variant=secondary) chips below trigger

### LabelsRenderer

- Same as `MultiSelectRenderer` — `allowedValues` from schema
- Chip style: `Badge` variant=outline (distinguishes labels from selects)

### ComponentPickerRenderer / VersionPickerRenderer

- `VirtualizedCombobox` with static `allowedValues` (from Phase 17 discovery)
- Multi-selection, Badge chips variant=secondary

### DateRenderer

- `<input type="date">` — browser native
- Classes: same as StringRenderer

### DateTimeRenderer

- `<input type="datetime-local">` — browser native
- Classes: same as StringRenderer

### NumberRenderer

- `<input type="number">` with `step="any"` to allow decimals
- Classes: same as StringRenderer

### CheckboxRenderer

- For `array<string>` with static `allowedValues`, renders one `<input type="checkbox">` per allowed value in a vertical stack
- Each row: `flex items-center gap-2 text-sm`

### RadioRenderer

- For single-select with explicit radio semantics, renders `<input type="radio">` per allowed value
- Grouped via `role="radiogroup"` with `aria-label` from field name

### UnsupportedTypeRenderer

- Read-only `Badge` variant=outline, icon: lucide `AlertCircle` (12px, `text-muted-foreground`)
- Text: `"Unsupported: {field.schema.type}"` — includes type for debugging (CONTEXT.md Specifics)
- No `onChange`. Not interactive.

## Interaction States

Every interactive renderer must implement all four states:

| State | Visual |
|-------|--------|
| Default | `border-input`, `bg-transparent` |
| Hover | `hover:bg-accent hover:text-accent-foreground` (Tailwind) |
| Focus | `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2` (accent ring `#c02232`) |
| Disabled | `disabled:opacity-50 disabled:pointer-events-none` |
| Required | Asterisk `*` appended to field label in `text-destructive` weight=semibold (visual only — no gating) |
| Loading (user picker) | Spinner in trigger right slot, trigger disabled during fetch |

## Copywriting Contract

Phase 20 delivers no full pages — all copy is within renderer components. All strings go through `useTranslation()` (i18next).

| Element | English copy | Slovak key path |
|---------|-------------|-----------------|
| Combobox trigger placeholder (no selection) | "Select…" | `fieldRenderer.placeholder.select` |
| User picker placeholder | "Search users…" | `fieldRenderer.placeholder.searchUsers` |
| User picker loading | "Searching…" | `fieldRenderer.placeholder.searching` |
| Combobox no results | "No results found." | `fieldRenderer.noResults` |
| UnsupportedType pill text | "Unsupported: {type}" | `fieldRenderer.unsupportedType` (with `{type}` interpolation) |
| Required field label suffix | " *" | `fieldRenderer.required` |
| MultiPicker clear chip aria-label | "Remove {name}" | `fieldRenderer.removeItem` (with `{name}` interpolation) |
| Date input aria-label | "{fieldName} date" | `fieldRenderer.dateLabel` |

Empty state (no values yet): combobox trigger shows placeholder copy above. No separate empty state illustration needed — this is a form control set, not a list page.

Error state: none in Phase 20 renderers. Errors are Phase 22's responsibility (required-field gating, failed lookup recovery).

Destructive actions: none in Phase 20.

## Accessibility Contract

All renderers must meet WCAG AA. This phase inherits the project-wide a11y decisions from Phase 9.

- Every `<input>`, `<textarea>`, combobox trigger must have `aria-label` or `<label htmlFor>` referencing the field name
- Combobox popover must have `role="listbox"` and each option `role="option"` with `aria-selected`
- `RadioRenderer` wraps options in `role="radiogroup"` with `aria-labelledby` pointing to the field label
- `CheckboxRenderer` wraps options in `role="group"` with `aria-labelledby`
- `UnsupportedTypeRenderer` has `role="status"` and `aria-label="Unsupported field type: {type}"`
- Focus must not be trapped — Tab leaves each renderer to the next
