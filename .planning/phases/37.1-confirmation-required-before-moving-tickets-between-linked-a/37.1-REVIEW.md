# Phase 37.1 Code Review

Scope: production changes in a532d84..HEAD (tests skimmed, not traced). Advisory.

## Warnings

### WR-01: Confirmed action depends on Radix `onCloseAutoFocus` firing
`ConfirmTransitionDialog.tsx:84-87`, `useTriageDetailActions.ts:144-170`. `onResolve(true)` only closes; the deny/link runs in `onClosed`, called from `onCloseAutoFocus`. If the content unmounts early the confirmed action is silently dropped and `resolvedTargetRef` stays populated. Fix: run the action from the confirm path; keep `onCloseAutoFocus` for focus return only.

### WR-02: Confirmed action can be silently discarded
`useTriageDetailActions.ts:152-168`. The stale-state guard (deny needs `copied`; link needs `ignored` + matching `copiedKey`) returns with no feedback. Fix: announce/toast "state changed, nothing was moved".

### WR-03: Ref written during render
`ConfirmTransitionDialog.tsx:36-37`. `lastTargetRef.current = target` mutates a ref in render (unsafe under StrictMode/concurrent). The `useEffect([target])` reset also lets a re-open flash `submitting=true` for one frame. Fix: keep the snapshot in state, or key the dialog by target.

### WR-04: Cancel relies on parent clearing `target`; Esc handled in two places
`ConfirmTransitionDialog.tsx:44-49,75`, `TicketDetailPage.tsx:111-115`, `TicketDetailPanel.tsx:129-133`. The page/panel guard checks `e.target.closest('[role="alertdialog"]')`; if focus is on `body`, Esc closes the dialog and also navigates back/closes the panel. Fix: gate on `tri.confirmDialog.target !== null` instead.
