# Phase 37.1 - UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

**Scope:** One new surface, `ConfirmTransitionDialog`, shown before a user-initiated move between Linked (`copied`) and Not mine (`ignored`, nav label "Dismissed" EN / "Zamietnute" SK). Two variants: `deny` (Linked to Not mine) and `link` (Not mine to Linked via "Restore link to KEY" when a remembered key exists). No other visible change. No new colors, sizes, tokens or icons.

Sources: 37.1-RESEARCH.md (no CONTEXT.md; user chose to proceed without discussion, so items marked (default) are the research defaults), 37-UI-SPEC.md (tokens, focus table, announcements), `src/features/groups/DeleteGroupDialog.tsx` (pattern to copy), `src/components/ui/dialog.tsx`, `src/components/ui/button.tsx`, `src/index.css`. Project feedback: explicit labelled buttons only, no drag and drop, SK says "tiket".

## Interaction Contract

### Dialog structure (copy `DeleteGroupDialog`)

| Property | Contract |
|----------|----------|
| Primitive | `Dialog` + `DialogContent` with `role="alertdialog"`, `hideClose`, className `max-w-[400px] p-6 bg-popover border-brand-border` |
| Content | `DialogTitle` (heading role), `DialogDescription` (body), action row `mt-6 flex justify-end gap-2` with Cancel (left) then Confirm (right). No inline error line (nothing fails inside the dialog; failures surface through the existing toasts after close) |
| Initial focus | `onOpenAutoFocus`: preventDefault, focus **Cancel** (safe default) |
| Dismissal | Esc and Cancel close with no side effect. `onInteractOutside` preventDefault (outside click does not dismiss). No close X |
| Esc isolation | Esc closes only the dialog, never the surrounding `TicketDetailPanel` (add `onEscapeKeyDown` stopPropagation if the test for the assumption fails) |
| Close focus | `onCloseAutoFocus`: preventDefault. On Cancel/Esc, explicitly focus the trigger (`denyRef` for deny, `primaryRef` for link). On Confirm, do not move focus; the hook's existing `pendingFocus` rules apply (deny: focus "Restore link to KEY" or Copy; link: Linked badge). `pendingFocus` is set only at confirm time |
| Busy | While the confirmed action is in flight, both buttons `disabled`; ignore double submit with a ref. Dialog closes immediately on Confirm (action continues; result reported by existing toast and `announce()`) |
| Snapshot | Keep the last target in a ref so title and body do not blank during the close animation |
| Stale guard | On Confirm, re-check the store: deny requires state still `copied`; link requires still `ignored` with the same remembered key; else close silently. Close the dialog if `issueKey` changes |
| Announcements | Do not `announce()` on open or cancel (Radix announces role, title, description). Result announcements unchanged (`a11y.denied`, `a11y.linked`) |
| Single instance | Opening is ignored while a dialog is pending or `linking` is true. Opening must not set `linking` |
| Mount | Rendered by `TicketDetailPage` and `TicketDetailPanel` from the shared hook state (`tri.confirm`); group view inherits through the shared detail. Triggers remain the existing labelled Deny and "Restore link to KEY" buttons (no new entry points, no row-level or hover-revealed controls) |

### When the dialog appears

| Trigger | Dialog? |
|---------|---------|
| Deny on a Linked ticket (page, panel, group view detail) | Yes, `deny` variant |
| "Restore link to KEY" on a Not mine ticket with a remembered key | Yes, `link` variant |
| Link/Copy on a never-linked ticket | No: the copy preview is the confirmation (default) |
| Undo toast action | No: it is the reversal affordance (default). It restores the true prior state only (relink only if prior state was `copied`) |
| Dismiss (New to Not mine), Restore (Not mine to New), Handled | No: not Linked transitions |
| "Don't ask again" option | None (default) |

## Copywriting Contract

Keys in `en.json` and `sk.json`; new `confirmLocale.test.ts` checks key parity, equal placeholders, SK contains "tiket" and never "uloh". Tab names come from existing labels via `{{tab}}`: deny uses `t('nav.notMine')` (EN "Dismissed", SK "Zamietnute"), link uses `t('nav.linked')`. Add `ConfirmTransitionDialog.tsx` to `EXTRA_FILES` in `noLiteralStrings.test.ts`.

| Element | Key | EN | SK |
|---------|-----|----|----|
| Deny title | `triage.confirm.deny.title` | Move {{key}} to {{tab}}? | Presunut {{key}} do {{tab}}? |
| Deny body | `triage.confirm.deny.body` | {{key}} is linked to {{cloudKey}}. The link is remembered and the Cloud ticket is not changed. You can undo this. | Tiket {{key}} je prepojeny s {{cloudKey}}. Prepojenie sa zapamata a tiket v Cloude sa nezmeni. Mozete to vratit spat. |
| Deny confirm (primary CTA) | `triage.confirm.deny.action` | Move to {{tab}} | Presunut do {{tab}} |
| Link title | `triage.confirm.link.title` | Restore link to {{cloudKey}}? | Obnovit prepojenie s {{cloudKey}}? |
| Link body | `triage.confirm.link.body` | {{key}} will move back to {{tab}}. No new Jira issue is created. | Tiket {{key}} sa presunie spat do {{tab}}. Nevytvori sa novy tiket v Jire. |
| Link confirm (primary CTA) | `triage.confirm.link.action` | Restore link | Obnovit prepojenie |
| Cancel | `triage.confirm.cancel` | Cancel | Zrusit |
| Empty state | - | not applicable (no data-driven surface) | - |
| Error state | - | No in-dialog errors. Failed actions reuse `triage.denyFailed` / `triage.linkFailed` toasts, also announced via live region (37-UI-SPEC) | existing |
| Destructive confirmation | - | none destructive; both variants are reversible confirmations (neutral/primary button, not red) | - |

Notes: the SK strings above are shown without diacritics for ASCII safety in this document only; the implementation must use proper Slovak diacritics (as in 37.1-RESEARCH.md, e.g. "Presunúť", "Zamietnuté", "Môžete to vrátiť späť") and reuse the existing SK wording for the Linked tab label (`nav.linked`, currently "Už prelinkované") so the body reads naturally; the planner should check that grammar with the interpolated label and rephrase the link body (for example "Tiket {{key}} sa vráti medzi prepojené") if the `{{tab}}` case does not fit. The link variant's `{{tab}}` is optional; if it hurts grammar use the literal wording above.
