**Change 3: copyStore.ts — Update progressStep during copy phases**

The current `confirmCopy` sets `progressStep: 'Creating ticket...'` at the start and then does a single `invoke('copy_ticket', ...)` call. Since the backend runs everything inside `copy_ticket`, the frontend cannot track individual attachment/comment/worklog progress in real time (it's a single Tauri invoke).

However, we should update the initial progress message to be more descriptive. Change the progressStep in the `set({ phase: 'copying' ...})` call to:

```typescript
set({ phase: 'copying', progressStep: 'Copying ticket with attachments, comments, and work log...' });
```

This provides a more accurate progress indication while the single invoke runs. The individual per-item progress (e.g., "Uploading attachment screenshot.png...") would require streaming from Rust, which is out of scope for this phase — the result modal shows per-item detail after completion.
