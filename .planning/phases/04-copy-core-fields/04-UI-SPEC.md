## Interaction Contract

### Copy Button (trigger)
- Location: TicketDetailPanel header row, to the right of the close button
- Label: "Copy to Company Jira"
- State: visible only when `detail` is loaded (not during loading skeleton)
- On click: invoke `fetch_cloud_meta` then open CopyPreviewModal (transitions copyStore to `loading_preview`)
- During `loading_preview`: button shows inline spinner (16px) replacing the text, disabled state
- Disabled style: `opacity-50 cursor-not-allowed`

### CopyPreviewModal
- Trigger: copyStore transitions to `previewing`
- Layout: fixed `inset-0 z-50`, backdrop `bg-black/60`, content area `flex flex-row h-full`
- Left column (source): 50% width, `bg-brand-surface`, scrollable, read-only field list + description preview using DescriptionRenderer
- Right column (target): 50% width, `bg-brand-surface-raised`, scrollable, editable fields
- Column divider: 1px `border-brand-border`
- Header bar: spans full width, `bg-brand-surface border-b border-brand-border`, contains modal title "Preview Copy" (13px semibold) and Cancel + Confirm buttons
- Cancel button: `text-brand-muted hover:text-brand-text`, no border, closes modal and resets copyStore
- Confirm button: accent-colored primary button "Copy to Company Jira", triggers copy pipeline
- Warning icon: amber triangle SVG (16×16) shown inline next to any target field that could not be auto-mapped from source
- Escape key: closes modal (same as Cancel)
- Focus trap: first interactive element in target column on open

### Editable Target Fields (right column)
- Status dropdown: native `<select>` with `bg-brand-surface border border-brand-border rounded px-2 py-1 text-sm`, populated from `availableStatuses`
- Priority dropdown: same style as status dropdown, populated from `availablePriorities`
- Labels checkboxes: each label on its own row with `<input type="checkbox">` + label text, all checked by default (D-09)
- Summary: read-only text field (not editable in this phase), displayed as plain text with muted styling
- Assignee: read-only, displays "Current user" as static text

### Copy-in-Progress
- CopyPreviewModal content dims: `opacity-50 pointer-events-none`
- Full-width progress bar appears below header: accent-colored, animated left-to-right indeterminate animation
- Step label displayed centered: "Creating ticket..." / "Converting description..." / "Uploading images..." / "Adding origin link..." (updated as each step completes)

### CopyResultModal
- Appears after `copying` → `result` transition
- Layout: centered card modal `max-w-md w-full bg-brand-surface rounded-lg shadow-xl p-6`
- Overlay: same `bg-black/60` backdrop
- Title: "Copy Complete" (success) or "Copy Finished with Errors" (partial/failure) — 16px semibold
- Result rows: each row `flex items-center gap-3 py-2 border-b border-brand-border-subtle last:border-0`
  - Green checkmark (emerald-400 SVG) or red X (red-400 SVG), 16×16
  - Step name in 14px regular
  - Optional detail text in 12px muted (e.g., created key, error reason)
- "Open in Company Jira" link: only shown if `create_issue` step succeeded. Full width button-style link, accent-colored text, opens via `open_external_url` Tauri command (established pattern from Phase 2)
- "Close" button: `text-brand-muted hover:text-brand-text`, closes modal and resets copyStore. Full width, below result rows.
- On close: ticket row in TicketTable updates triage state to `copied` with target key badge (D-14)

### TriageIndicator Extension (target key badge)
- When `state === 'copied'` and `copiedKey` prop is provided:
  - Render green checkmark SVG (existing, 16×16)
  - Append `<span class="ml-1 text-[11px] font-medium text-emerald-400 hover:underline cursor-pointer">{copiedKey}</span>`
  - On span click: invoke `open_external_url` with the company Jira ticket URL

## Accessibility

- CopyPreviewModal: `role="dialog" aria-modal="true" aria-labelledby="preview-modal-title"`
- CopyResultModal: `role="dialog" aria-modal="true" aria-labelledby="result-modal-title"`
- Focus trap: active inside modal while open; returns focus to "Copy to Company Jira" button in TicketDetailPanel on close
- Escape key: closes both modals
- Progress bar: `role="progressbar" aria-label="Copy in progress"` with `aria-valuenow` updating per step
- All SVG icons: `aria-hidden="true"` (decorative); checkmark/X icons in result rows use sibling text as the accessible label
- Dropdowns: native `<select>` elements — accessible by default
- Checkboxes: native `<input type="checkbox">` with `<label>` association via `htmlFor`
