## Phase Classification

**UI hint: none — backend-only Rust refactor phase.**

Phase 23 is entirely a Rust backend change. There are no new React components, no new screens, no new visual states, and no design decisions required. All design system dimensions are not applicable.

The sole frontend change is a single line in `src/features/tickets/copyStore.ts`:

```diff
- invoke('copy_ticket', { ... })
+ invoke('copy_ticket_v2', { args: { sourceKey, sourceBaseUrl, targetBaseUrl, targetIssueTypeId, overrideValues } })
```

This is a call-site swap, not a UI change. The user-visible behavior, loading states, error states, and success states are unchanged. The existing `CopyTicketResult { target_key, target_url, steps: Vec<CopyStepResult> }` return shape is preserved by design (CUTV-01 / 23-CONTEXT.md D-03).
