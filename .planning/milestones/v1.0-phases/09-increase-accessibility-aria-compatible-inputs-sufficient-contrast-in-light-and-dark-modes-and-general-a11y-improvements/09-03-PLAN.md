**ConnectionForm.tsx — URL error aria-describedby:**

1. On the base URL `<input id="base-url">`, add:
   - `aria-invalid={!!urlError}` attribute
   - `aria-describedby={urlError ? "base-url-error" : undefined}` attribute

2. On the error `<p>` element (currently `<p className="text-xs text-red-400">{urlError}</p>`), add:
   - `id="base-url-error"` attribute
   - `role="alert"` attribute

The input element should look like:
```tsx
<input
  id="base-url"
  type="url"
  value={baseUrl}
  onChange={(e) => handleBaseUrlChange(e.target.value)}
  onBlur={handleUrlBlur}
  disabled={testing}
  aria-invalid={!!urlError}
  aria-describedby={urlError ? "base-url-error" : undefined}
  placeholder={...}
  className={inputClass}
/>
```

The error element should look like:
```tsx
{urlError && (
  <p id="base-url-error" role="alert" className="text-xs text-red-400">{urlError}</p>
)}
```

**TicketListPage.tsx — fetch status live region:**

The fetch bar `<span>` that shows last-fetched time or "Not yet fetched" text should have `aria-live="polite"` to announce fetch completion:
```tsx
<span className="text-xs text-brand-muted" aria-live="polite">
  {lastFetchedAt ? t('tickets.lastFetched', { time: formatRelativeTime(lastFetchedAt) }) : t('tickets.notYetFetched')}
</span>
```

Note: The error state div already has `role="alert"` — no change needed there. The SkeletonCards already has `aria-busy="true"` — no change needed there either. Only the fetch status text needs the live region addition.
