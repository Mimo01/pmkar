## Spacing Scale

Declared values (multiples of 4 only). Sourced from 8-point scale — default.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline chip spacing |
| sm | 8px | Button internal padding (horizontal), card row gaps |
| md | 16px | Card padding, section padding, form field gaps |
| lg | 24px | Between card groups, settings section top margin |
| xl | 32px | Page content horizontal padding, modal internal padding |
| 2xl | 48px | Major section breaks in SettingsPage |
| 3xl | 64px | Empty state vertical centering offset |

Exceptions:
- Header height: 44px (touch target minimum — preserves current `py-2.5 px-5` pattern with icon buttons at 28px × 28px)
- Tab nav height: 36px (current `py-2` with `text-sm` — retain for compactness)
- Ticket card: 12px vertical padding (between sm 8px and md 16px) — Linear-style compact row feel

## Typography

System font stack throughout. No custom font loading (Tauri desktop — no web font latency tradeoff needed).

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px | 400 (regular) | 1.5 |
| Label / Metadata | 12px | 400 (regular) | 1.4 |
| Heading (section, card summary) | 14px | 600 (semibold) | 1.4 |
| Display (page title, modal title) | 16px | 600 (semibold) | 1.2 |

Notes:
- Two weights only: 400 (regular) and 600 (semibold). No weight 500 anywhere.
- App branding "pmkar" in header: 12px, weight 600, tracking-tight — uses Label size tier
- Ticket key in card top row: 12px, weight 400, `font-mono` — monospace family alone provides visual distinctiveness; no separate weight needed
- Line height 1.5 for body text ensures comfortable reading density for description content
- Heading line height 1.2 for display/modal titles is appropriate for single-line headings

## Color

Existing tokens in `src/index.css` are the canonical source. The redesign refines usage rules — token values are already correct.

| Role | Light Value | Dark Value | Usage |
|------|------------|-----------|-------|
| Dominant (60%) | `#f7f7f8` (`--color-brand-bg`) | `#161617` | Page background, window fill |
| Secondary (30%) | `#ffffff` (`--color-brand-surface`) | `#1e1e20` | Cards, header, nav bar, modals, settings sections |
| Accent (10%) | `#c02232` (`--color-brand`) | `#c02232` | See reserved list below |
| Destructive | `#dc2626` (Tailwind `red-600`) | `#dc2626` | Ignore action confirmation only |

**Accent `#c02232` reserved for:**
1. Active tab indicator underline (2px bottom border on active nav tab)
2. Brand wordmark "pm" prefix in header
3. Header brand accent gradient underline (`from-brand via-brand/60 to-transparent`)
4. Copy button (primary action CTA) — filled background
5. Active triage state dot (copied status indicator)
6. Audit count badge background
7. Focus rings (`focus-visible:ring-brand`) — keyboard navigation only, not pointer interaction

Accent is NOT used for: hover states, form borders, informational badges, general links.

**Supporting semantic colors (from existing token set):**
- Muted text: `--color-brand-muted` (`#8c8c92` light / `#6b6b6f` dark) — metadata, timestamps, placeholder
- Secondary text: `--color-brand-text-secondary` (`#5c585a` light / `#95959a` dark) — assignee, priority label
- Border: `--color-brand-border` (`#e0e0e3` light / `#2e2e30` dark) — card outlines, dividers
- Surface hover: `--color-brand-surface-hover` (`#f0f0f2` light / `#28282a` dark) — card hover, button ghost hover

**Status badge colors (ticket status — informational only, not accent):**
- In Progress: `#2563eb` (blue-600) background at 10% opacity, blue-600 text
- Done / Resolved: `#16a34a` (green-600) background at 10% opacity, green-600 text
- To Do / Open: muted surface with secondary text
- Blocked: `#dc2626` (red-600) background at 10% opacity, red-600 text

**Priority dot colors:**
- Highest / Critical: `#dc2626`
- High: `#ea580c`
- Medium: `#ca8a04`
- Low: `#3b82f6`
- Lowest: `--color-brand-muted`

## Primary Focal Point

**TicketListPage (main screen):** The ticket card list is the primary visual anchor. The first visible ticket card at the top of the list is the focal point entry. Visual hierarchy is established by:
- The ticket summary (card title line) at 14px weight 600 as the most prominent text element per card
- Cards rendered flush against each other with only `--color-brand-border` dividers — no whitespace between cards — directing eye downward through the list
- The "Copy to Company Jira" button as the single accent-filled element per card on hover, drawing action focus

All other UI elements (header, tabs, metadata) are secondary to the card list.

## Interaction Contracts

### Card hover (ticket cards)

- Transition: `background-color 150ms ease` to `--color-brand-surface-hover`
- Border: `--color-brand-border` at rest; `--color-brand-border` unchanged on hover (no border color change — Linear pattern)
- Cursor: `pointer`
- No box-shadow change on hover (flat aesthetic)

### Navigation tabs

- Active tab: `--color-brand-text` color, weight 600, 2px `--color-brand` bottom border
- Inactive tab: `--color-brand-muted` color, weight 400, 2px transparent bottom border
- Transition: `color 150ms ease, border-color 150ms ease`

### Full-page detail navigation (CONTEXT.md D-10)

- Clicking a ticket card navigates to a full-page detail view (not a side panel)
- Back button in detail page header returns to the ticket list preserving active tab state
- Transition: no page transition animation (Tauri desktop — instant navigation is faster and more appropriate than animated slide)

### Copy modal (CONTEXT.md D-18)

- CopyPreviewModal opens as a Dialog (shadcn `dialog`) — centered overlay, max-width 560px
- Progress visualization: shadcn `progress` component with step labels below (not a spinner alone)
- Step labels update in real time as copy proceeds
- CopyResultModal reuses Dialog pattern — shows per-item result table (attachments: N copied, M failed)

### Loading skeletons (CONTEXT.md D-19)

- Use shadcn `skeleton` for ticket list loading state (3 placeholder card shapes)
- Skeleton card height: 72px (matches compact 3-line card)
- No spinner in list area — skeletons only
- Header fetch button shows a spinner icon (Lucide `Loader2` with `animate-spin`) while fetch is in progress

### Settings page sections (CONTEXT.md D-16)

- Left sidebar nav (section list) + right content area layout
- Sidebar width: 160px, fixed
- Section nav items: 14px, weight 400, `--color-brand-muted`; active: weight 600, `--color-brand-text`
- Active section indicator: 2px `--color-brand` left border on active nav item
- No accordion — all sections are full-page replacements within the settings layout

### Focus rings

- Use Tailwind `focus-visible:ring-2 focus-visible:ring-brand focus-visible:ring-offset-2`
- Ring color: `--color-brand` (`#c02232`) — consistent with accent item 7 in Color section above
- Ring offset color: matches surface background
- Applied on keyboard navigation only (`focus-visible`, not `focus`) — does not appear on pointer click

### Animations

- CSS transitions only — no Framer Motion or animation library (keeps bundle lean for Tauri desktop)
- All transitions: 150ms ease (fast, Linear-inspired feel)
- Exception: Copy progress bar fill — 300ms ease for smooth visual feedback
