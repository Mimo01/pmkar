**1. Create `src-tauri/src/triage_db.rs`:**

Follow the `AuditDb` pattern (struct wrapping `rusqlite::Connection`, `open(path)` method that creates tables).

```rust
pub struct TriageDb { conn: Connection }
```

Two tables created in `open()`:

```sql
CREATE TABLE IF NOT EXISTS triage_state (
    ticket_key   TEXT PRIMARY KEY,
    state        TEXT NOT NULL CHECK(state IN ('new','seen','ignored','copied')),
    first_seen   TEXT NOT NULL,
    last_updated TEXT NOT NULL
);
CREATE TABLE IF NOT EXISTS fetch_config (
    id              INTEGER PRIMARY KEY CHECK(id = 1),
    jql_preset      TEXT NOT NULL DEFAULT 'assigned',
    jql_custom      TEXT,
    watched_users   TEXT NOT NULL DEFAULT '[]',
    last_fetched_at TEXT
);
```

Methods on `TriageDb`:
- `open(path: &Path) -> AppResult<Self>` — opens DB, creates tables, inserts default fetch_config row if none exists (`INSERT OR IGNORE INTO fetch_config(id) VALUES(1)`)
- `open_in_memory() -> AppResult<Self>` — for tests
- `get_all_triage() -> AppResult<HashMap<String, String>>` — returns `{ticket_key: state}` map
- `set_triage(key: &str, state: &str) -> AppResult<()>` — upsert: `INSERT INTO triage_state ... ON CONFLICT(ticket_key) DO UPDATE SET state=?2, last_updated=?3`
- `get_fetch_config() -> AppResult<FetchConfig>` — reads the single row
- `set_fetch_config(config: &FetchConfig) -> AppResult<()>` — updates the single row

Define `FetchConfig` struct:
```rust
#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct FetchConfig {
    pub jql_preset: String,       // "assigned" | "mentioned" | "all_watched" | "custom"
    pub jql_custom: Option<String>,
    pub watched_users: Vec<String>, // deserialized from JSON text column
    pub last_fetched_at: Option<String>, // ISO 8601
}
```

**Command 1: `fetch_tickets`**
```rust
#[derive(serde::Serialize, Clone, Debug)]
pub struct FetchTicketsResult {
    pub issues: Vec<serde_json::Value>,  // array of {id, key, fields:{summary, status, priority, assignee, updated}}
    pub total: u64,
    pub triage_map: std::collections::HashMap<String, String>, // key -> state
}

#[tauri::command]
pub async fn fetch_tickets(
    base_url: String,
    jql: String,
    db: State<'_, Arc<Mutex<AuditDb>>>,
    triage_db: State<'_, Arc<Mutex<TriageDb>>>,
) -> Result<FetchTicketsResult, AppError>
```
- Get PAT from keychain: `keychain::get_credential("server", "pat")?`
- Build audited client: `build_audited_client(Arc::clone(db.inner()))`
- Call `GET {base_url}/rest/api/2/search?jql={urlencoded_jql}&fields=summary,status,priority,assignee,updated&maxResults=50` with `Authorization: Bearer {pat}`
- Parse response JSON: extract `issues` array and `total`
- For each issue key: call `triage_db.set_triage(key, "new")` only if key not already in triage_state (check with get_all_triage first). Mark existing keys as-is.
- Update `last_fetched_at` in fetch_config to `chrono::Utc::now().to_rfc3339()`
- Return `FetchTicketsResult` with issues, total, and full triage_map
