**1. Create `src/features/tickets/DescriptionRenderer.tsx`:**

Renders description as HTML. For v2 (Server), use `renderedFields.description` HTML string. For v3 (Cloud ADF), fall back to stringified JSON for now (simple-adf-formatter integration deferred — plain text fallback is acceptable for MVP, Cloud is "Company Jira" destination, not source).

For v2 renderedFields HTML: use `dangerouslySetInnerHTML`. Post-process images via `useEffect` — after rendering, find all `img` elements in the container and replace `src` with invoke('fetch_jira_image') result.

```tsx
import { useRef, useEffect } from 'react';
import { invoke } from '@tauri-apps/api/core';

interface DescriptionRendererProps {
  description: string | Record<string, unknown> | null;
  renderedHtml?: string;
  baseUrl: string;
}
```

If `renderedHtml` is a non-empty string: render it with `dangerouslySetInnerHTML` in a div with prose-like classes: `text-sm text-slate-300 leading-relaxed [&_h1]:text-slate-200 [&_h1]:font-semibold [&_h1]:text-lg [&_h1]:mt-4 [&_h1]:mb-2 [&_h2]:text-slate-200 [&_h2]:font-semibold [&_h2]:text-base [&_h2]:mt-3 [&_h2]:mb-1 [&_a]:text-blue-400 [&_a]:hover:underline [&_code]:bg-slate-800 [&_code]:px-1 [&_code]:py-1 [&_code]:rounded [&_code]:text-xs [&_code]:font-mono [&_code]:text-emerald-300 [&_blockquote]:border-l-2 [&_blockquote]:border-slate-600 [&_blockquote]:pl-3 [&_blockquote]:text-slate-400 [&_p]:mb-2 [&_ul]:list-disc [&_ul]:pl-5 [&_ol]:list-decimal [&_ol]:pl-5`.

After render, `useEffect` walks `containerRef.current.querySelectorAll('img')` and for each img:
```typescript
try {
  const dataUrl = await invoke<string>('fetch_jira_image', { imageUrl: img.src, baseUrl });
  img.src = dataUrl;
} catch {
  img.alt = '[image unavailable]';
  img.removeAttribute('src');
}
```

If `renderedHtml` is empty/undefined but `description` is a non-empty string: render as `<pre>` with `text-sm text-slate-300 whitespace-pre-wrap`.

If `description` is an object (ADF): render `JSON.stringify(description, null, 2)` in `<pre>` with `text-xs text-slate-400 font-mono whitespace-pre-wrap` (ADF rendering deferred to Phase 4 or later).

If `description` is null/empty: render `<p className="text-xs text-slate-500 italic">No description</p>`.
