  <action>
1. **src-tauri/src/main.rs** — Add plugin registration inside the `setup()` closure, BEFORE the existing AuditDb/TriageDb setup. Add a `#[cfg(desktop)]` gated block:

```rust
#[cfg(desktop)]
{
    app.handle().plugin(tauri_plugin_updater::Builder::new().build())?;
    app.handle().plugin(tauri_plugin_process::init())?;
}
```

This requires adding `use tauri::Manager;` (already imported) at the top. The `app.handle()` method is from the `Manager` trait.

Note: In dev mode with `mock-server` feature, the updater check will naturally fail (no published releases) — this is fine. The frontend will handle the error silently per D-04.

2. **src-tauri/capabilities/main.json** — Create new directory `src-tauri/capabilities/` and file `main.json`:

```json
{
  "$schema": "../gen/schemas/desktop-schema.json",
  "identifier": "main-capability",
  "description": "Main window capabilities",
  "windows": ["main"],
  "permissions": [
    "core:default",
    "updater:default",
    "updater:allow-check",
    "updater:allow-download-and-install",
    "process:default",
    "process:allow-restart"
  ]
}
```

Without this file, all updater frontend calls will fail with "Not allowed" or silently fail per Pitfall 5 in RESEARCH.md.

3. **src-tauri/tauri.conf.json** — Add `createUpdaterArtifacts` to bundle section and add `plugins.updater` section:

- In the `"bundle"` object, add: `"createUpdaterArtifacts": true` (after `"targets": "all"`)
- Add a top-level `"plugins"` object:

```json
"plugins": {
  "updater": {
    "pubkey": "PLACEHOLDER_GENERATE_WITH_tauri_signer_generate",
    "endpoints": [
      "https://github.com/AurelianSpowormo/pmkar-releases/releases/latest/download/latest.json"
    ]
  }
}
```

The pubkey is a placeholder — the user must generate a real signing keypair before the first release (documented in Plan 02 user_setup). The endpoint URL uses the public releases repo pattern per D-01.

Per D-09/D-10/D-11: No Apple notarization or Windows code signing configured — workflow structured so these can be added later via GitHub secrets.
