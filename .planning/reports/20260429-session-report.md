## Work Performed

### Quick Task: user_name transformer (260429-un1)

**Goal:** Add a transformer that copies a person's display name as plain text when a
source `user` field is mapped to a destination `string`/`text` field.

**Gap discovered:** Neither `identity` (returns Null for user types) nor `user` (resolves
accountId — wrong shape for text fields) worked for this mapping combination. The pipeline
also entirely ignored `transformer_kind` for user-sourced fields — it always dispatched
to accountId resolution regardless.

### Key Outcomes

- **New `user_name` transformer** — extracts `displayName` (fallback: `name`) from a
  source user object and writes a plain string. Array<user> joins names with `", "`.
- **Pipeline fix** — `transformer_kind` is now respected for user fields. `"user_name"`
  routes to `dispatch_user_name()`; everything else continues to `dispatch_user()`.
- **`getTransformerOptions` extended** — accepts an optional `sourceSchema` parameter.
  When source=user AND target=string, exclusively offers `[USER_NAME]` (no misleading
  `IDENTITY` or `WIKI_TO_ADF` options that would silently produce nothing useful).
- **Auto-select corrected** — `MappingRow.tsx` and `SuggestionsPanel.tsx` now pass
  `sourceSchema` so the default transformer is correct when selecting/suggesting targets.
- **5 new Rust tests** — displayName extraction, name fallback, array join, null user
  skip, regression guard for standard `user` transformer.
